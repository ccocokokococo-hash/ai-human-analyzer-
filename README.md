
# AI or Human? English Text Analyzer

This is a practical digital product for the research project:

**“AI vs Human Writing: What is the Difference in English Texts?”**

## Project Information

- Student: Bulat Leila
- Grade: 8
- School: Auzhan KTL Multilingual Lyceum
- Supervisor: Akbolatova Aidana Erlankyzy

## Purpose

The website helps students compare AI-written and human-written English texts.
It is designed as an interactive digital workbook for English lessons.

## Main Features

- AI vs Human writing theory
- Text analyzer for any English text
- AI-like and Human-like percentage
- Checklist for students
- Mini quiz
- Experiment results section
- Recommendations and conclusion

## Important Note

This website is an educational heuristic analyzer.
It is not a professional AI detector.
It helps students notice writing features such as:

- grammar
- vocabulary
- structure
- emotions
- personal examples
- writing style

## How to Use

1. Open `index.html` in your browser.
2. Paste or write an English text in the analyzer.
3. Click **Analyze Text**.
4. Read the result and feedback.
5. Try the mini quiz.

## GitHub Pages

To publish the site:

1. Create a new GitHub repository.
2. Upload all files.

4. Choose branch `main`.
